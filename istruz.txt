== 0. Avvio container (dal host) ==

cd ~/Scrivania/ElectiveAI
bash start_tiago.sh


== 1. Gazebo ==

docker exec -it hrai_sim bash
source /opt/ros/humble/setup.bash
source /root/tiago_public_ws/install/setup.bash
source /root/exchange/install/setup.bash
export GAZEBO_MODEL_PATH=/root/exchange/exchange/models:${GAZEBO_MODEL_PATH:-}
ros2 launch tiago_gazebo tiago_gazebo.launch.py \
  is_public_sim:=True \
  gazebo_version:=classic \
  world_name:=/root/exchange/exchange/scene.world


== 2. Nav2 ==

docker exec -it hrai_sim bash
source /opt/ros/humble/setup.bash
source /root/tiago_public_ws/install/setup.bash
source /root/exchange/install/setup.bash
ros2 launch empower tiago_nav2_ground_truth.launch.py \
  map:=/root/exchange/exchange/maps/scene.yaml


== 3. Build + Missione ==

docker exec -it hrai_sim bash
cd /root/exchange
source /opt/ros/humble/setup.bash
source /root/tiago_public_ws/install/setup.bash
rm -rf build/empower install/empower build/llm_interaction install/llm_interaction
colcon build --symlink-install --packages-select llm_interaction empower
source /root/exchange/install/setup.bash
rm -rf /root/exchange/output/empower_output/therapy_task
ros2 launch empower hri_empower_mission.launch.py \
  hri_params_file:=/root/exchange/src/llm_interaction/config/llm_config.yaml \
  hri_input_mode:=voice \
  stt_device_index:=4


== Note ==

- Ollama deve girare sull'host: ollama serve
- Modello richiesto: ollama pull gemma3:12b
- Il build va fatto prima della missione perche' ci sono file nuovi (session_scores.py)
- Dopo il primo build riuscito, per rilanci successivi basta:
    source /root/exchange/install/setup.bash
    ros2 launch empower hri_empower_mission.launch.py \
      hri_params_file:=/root/exchange/src/llm_interaction/config/llm_config.yaml \
      hri_input_mode:=voice \
      stt_device_index:=4
- Per terminare l'attivita' in modo graceful: premere 'q' nel terminale della missione
